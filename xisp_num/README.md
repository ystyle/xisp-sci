# xisp_num

星枢科学计算数值方法：插值、多项式拟合、数值积分、一维优化、ODE。

```lisp
(cangjie::interp1 x y xi)                 ; 一维线性插值
(cangjie::polyfit x y 2)                  ; 二次拟合，返回降幂系数
(cangjie::polyval coef 3.0)               ; 多项式求值
(cangjie::trapz y 0.1)                    ; 梯形积分
(cangjie::simpson y 0.1)                  ; Simpson 积分
(cangjie::fmin (lambda (x) (* (- x 2) (- x 2))) 0 5)   ; 一维极小
(cangjie::rk4 (lambda (t y) y) 1.0 0.0 1.0 0.05)       ; ODE → {t, y}
```

## 接口稳定性

每个符号的**调用形式**是契约，内部算法可换：

- `fmin` 现在黄金分割，将来换 Brent 不影响调用方
- `rk4` 是固定步长，将来加自适应版本时**另开符号**（`ode45` 之类），不改 `rk4`
- `polyfit` 现在正规方程，将来换 QR 也对调用方透明

## 设计要点

**插值在区间外 clamp 到端点**，不硬外推。线性插值没有外推的依据；硬外推在
金融/工程数据上会给出荒唐的值。

**`x` 必须严格升序**（自动检查）。插值要求能唯一确定区间，乱序的 x 会让二分
查找给出错误的邻居。

**Simpson 点数必须为奇数**（偶数个区间）。不满足时**报错**而不是退回梯形——
静默降级会让调用方以为拿到了 Simpson 的精度。

**`fmin` 只保证在给定区间上找单峰极值**。多峰函数会落到其中一峰，这是算法的
前提而不是 bug，文档里说清楚比假装全能好。

**RK4 的测试验收敛阶而不只是"结果接近"**：步长减半时误差应降约 16 倍
（四阶）。只验证"对"是不够的 —— 一个二阶方法在粗步长下也可能看起来对，
但外推到精细步长就会暴露。

**`num` 域声明为 `escapable`**：`fmin` / `rk4` 要回调 Lisp 函数，那是"执行宿主
代码"而不是纯数据运算，与 `array` / `linalg` 的纯计算域不同。
