# xisp_linalg

星枢科学计算线性代数：矩阵乘法、LU / QR / Cholesky 分解、解方程与求逆。

**纯仓颉实现，零外部依赖** —— 不接 BLAS / LAPACK。`cjpm` 没有可选依赖，接 C 库意味着
每个用本模块的宿主都得装 C 工具链，与 `xisp_array` 一直守着的零依赖前提冲突。

```lisp
(cangjie::matmul A B)                        ; 矩阵乘法（含向量 / 点积）
(cangjie::det A)                             ; 行列式
(cangjie::solve A b)                         ; 解 A x = b
(cangjie::inv A)                             ; 逆矩阵
(cangjie::trace A)                           ; 迹
(cangjie::cholesky A)                        ; 对称正定 → L（A = L Lᵀ）
(cangjie::lu A)                              ; {"l": …, "u": …, "p": …}（P A = L U）
(cangjie::qr A)                              ; {"q": …, "r": …}（Q R = A）
```

## `matmul` 的维度组合

一维数组在 **A 位置当行向量、B 位置当列向量**（与 `y = A x` 的书写顺序一致）：

| A | B | 结果 |
|---|---|---|
| `2D (m,k)` | `2D (k,n)` | `2D (m,n)` |
| `1D (k)` | `2D (k,n)` | `1D (n)` |
| `2D (m,k)` | `1D (k)` | `1D (m)` |
| `1D (k)` | `1D (k)` | **标量**（点积） |

## 设计要点

**一律按 Float64 计算**，Int 数组自动提升。

**部分主元不是可选项**。`[[0,1],[1,0]]` 第一步主元就是 0，不选主元会直接除零；
`[[1e-20,1],[1,1]]` 这类矩阵会得到灾难性的误差放大。

**奇异 / 非正定 / 非对称一律报错**，不返回垃圾值 —— 一个"看起来像逆矩阵"的东西被下游
继续用，比一次明确的报错危险得多。奇异判定用**相对容差**（乘以矩阵元素最大绝对值），
不写死绝对阈值。

**`lu` 返回的 `p` 是累积后的最终置换**（1-based：`p[i]` 表示 `PA` 的第 i 行来自原矩阵的
第 `p[i]` 行），满足 `P A = L U`。注意它不是 LAPACK 那种"每步与谁交换"的中间量 ——
直接拿中间量当置换会得到非法矩阵。

**Cholesky 比 LU 快一倍且不需要选主元**（对称正定保证主元恒正），所以有对称正定结构时
优先用它。

**QR 用 Householder 反射**，不是 Gram-Schmidt —— 古典 Gram-Schmidt 在近乎线性相关的列上
会严重丢失正交性。
