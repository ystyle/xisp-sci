# 数值方法

## 插值

```lisp
(cangjie::interp1 x y xi)
```

`x` 必须**严格升序**（自动检查）。插值要求能唯一确定区间，乱序的 `x` 会让二分查找
给出错误的邻居，而这个过程不会报错，只会给出一个看着正常的错值。

区间外**钳到端点**，不硬外推。线性插值没有外推的依据；硬外推在金融、工程数据上会
给出荒唐的值。

## 多项式拟合

```lisp
(cangjie::polyfit x y 2)      ; 二次拟合，返回降幂系数
(cangjie::polyval coef 3.0)   ; 求值
```

系数是**从高次到低次**（`c[0]·x² + c[1]·x + c[2]`），与常见习惯一致。

用正规方程 `VᵀV c = Vᵀy` 直接解。对低阶（≤ 6）没问题；高阶时 Vandermonde 矩阵条件数
会爆炸，那时应该换正交多项式基，接口不变。

## 数值积分

```lisp
(cangjie::trapz y 0.1)           ; 等距梯形
(cangjie::trapz x y)             ; 变距梯形
(cangjie::simpson y 0.1)         ; Simpson
```

**Simpson 要求点数为奇数**（偶数个区间）。不满足时报错而不是退回梯形。静默降级会让调用方以为拿到了 Simpson 的精度。

Simpson 对二次多项式精确而梯形有误差，这是它存在的理由。测试不是验证「都对」，
而是验证**这个阶数差异确实存在**。

## 一维优化

```lisp
(cangjie::fmin (lambda (x) (* (- x 2) (- x 2))) 0 5)     ; → 2.0
(cangjie::fmin f a b 1e-8)                               ; 指定容差
```

黄金分割法。只在 `[a,b]` 上找单峰极值，多峰函数会落到其中一个峰，
这是算法的前提而不是 bug。

## 常微分方程

```lisp
(define r (cangjie::rk4 (lambda (t y) y) 1.0 0.0 1.0 0.05))
;; → {"t": ndarray, "y": ndarray}   —— dy/dt = y 的解是 eᵗ
```

固定步长 RK4。

**验证方式是验收敛阶，不只是「结果接近」**：步长减半时误差应降约 16 倍（四阶）。
只验证「对」是不够的：一个二阶方法在粗步长下也可能看起来对，但外推到精细步长
就会暴露。

## 接口稳定性

每个符号的**调用形式**是契约，内部算法可换：

- `fmin` 现在黄金分割，将来换 Brent 不影响调用方
- `rk4` 是固定步长，将来加自适应版本时**另开符号**（`ode45` 之类），不改 `rk4`
- `polyfit` 现在正规方程，将来换 QR 也对调用方透明
