# 回归：从相关到预测

## 最小二乘

```lisp
;; G3 ≈ b0 + b1·G1 + b2·G2（含截距列）
(cangjie::lstsq X y)      ; X 是 n×p，y 是 n
;; → #<ndarray float64 [-1.83 0.153 0.987]>
```

用法就这一行。麻烦的是**构造设计矩阵**：`X` 要包含截距列。

```lisp
;; 从 CSV 拿三列，拼成 n×3
(define g1 (hashmap-get d "G1"))
(define g2 (hashmap-get d "G2"))
(define y  (hashmap-get d "G3"))
;; …构造 X = [1, G1, G2]…
```

> ⚠️ **已知缺口**：Lisp 层还没有 `hstack` / `concat`。目前要在宿主语言侧拼列，
> 或者用 `cangjie::reshape` 手工绕。这是下一步要补的。

## 为什么走 QR 而不是正规方程

正规方程是 `b = (XᵀX)⁻¹Xᵀy`，教科书上都这么写。但它的**条件数会被平方**：

```
cond(XᵀX) = cond(X)²
```

一个条件数 1e6 的设计矩阵，直接变成 1e12。双精度只有约 1e16 的有效范围，
一下子就用掉了一大半。

`lstsq` 走 QR：`X = QR`，则 `b = R⁻¹Qᵀy`，只把 `Qᵀy` 的前 n 个分量回代，
**不显式求逆**，条件数不平方。

## 秩亏会报错

两个特征完全线性相关时（一列是另一列的两倍），系数不唯一，有无穷多组解。

这时 `lstsq` 抛错而不是返回其中某一个。静默给出一个「解」会让用户以为找到了唯一答案，
而实际上任何一组都同样「正确」。

真实数据里遇到这个错误，正确的反应是**去掉相关特征中的一个**，而不是想办法绕过报错。

## 拟合优度自己算

`lstsq` 只给系数。R² 和 RMSE 需要自己从预测值算：

```lisp
(define pred (cangjie::matmul X b))
;; 残差 = y - pred
;; R² = 1 - SS_res / SS_tot
```

没有内建 `r2` 函数是刻意的：R² 的计算方式有好几种（是否含截距、是否调整、
广义线性模型用什么替代），把它们变成一个函数会诱使人不去想自己在算什么。
自己写这两行反而更清楚。

## 读系数要看前提

Auto MPG 数据集的多元回归（7 个特征）结果是：

| 特征 | 系数 | 说明 |
|---|---|---|
| `weight` | -0.0064 | 车重每多 1000 磅，MPG 低约 6.4 |
| `year` | +0.7507 | 每新一年，MPG 高 0.75 |
| `origin` | +1.4261 | 非美国产高 1.4 |
| `cylinders` | -0.4933 | ？？？ |
| `displacement` | +0.0198 | ？？？ |
| `horsepower` | -0.0169 | ？？？ |

后三个系数都很小，但这并不是因为它们不重要。它们与 `weight` 高度共线
（大排量车通常也重），线性模型无法把各自的影响分开。

把 `weight` 拿掉后，`horsepower` 的系数会显著变大。

**所以「哪个特征最重要」不能只看系数绝对值**，要看它和其它特征的关系。
这就是为什么回归系数必须结合上下文解释，而不是读一个排名。
