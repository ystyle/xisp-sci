# 描述统计

`xisp_stats` 的 36 个符号里，最常用的是一组基础统计量（分布函数那一族在[分组与假设检验](/guide/05-inference)里讲）。

## 集中趋势与离散程度

```lisp
(define x (cangjie::array [2.0 4.0 4.0 4.0 5.0 5.0 7.0 9.0]))

(cangjie::mean x)         ; 5.0
(cangjie::median x)       ; 4.5
(cangjie::std x)          ; 2.138 —— 样本标准差（除 n−1）
(cangjie::std-pop x)      ; 2.000 —— 总体标准差（除 n）
(cangjie::var x)          ; 4.571 —— 样本方差
```

### `std` 默认是样本标准差

除以 `n−1`，不是 `n`。**这与 NumPy 相反**：`np.std` 默认 `ddof=0`（总体），
`np.std(ddof=1)` 才是样本。

选样本作默认，是因为数据分析里手上的数据多数时候是样本。「我有的全部数据」这种
情形在真实工作中不常见。要总体标准差时显式用 `cangjie::std-pop`。

这个区别不是细节：Boston 的 `medv` 列，样本标准差 9.1971、总体标准差 9.1880，
差在第四位。拿错了对不上任何公开基准值。

## 分位数

```lisp
(cangjie::quantile x 0.25)     ; 4.0
(cangjie::quantile x 0.5)      ; 4.5 —— 与 median 一致
(cangjie::quantile x 0.9)      ; 6.4
```

用**线性插值**，等价于 R 的 `quantile(type=7)`、NumPy 的 `percentile` 默认值。

分位数有 9 种算法（R 的 `type=1..9`），不同的定义在样本量小、或数据有大量重复值时
给出明显不同的结果。这里只实现一种，因为约定比选项重要：选最常见的那个并在
文档里写清，比给 9 个选项让人选错要好。

## 最值：两套语义

```lisp
(min x)  (max x)              ; 数学语义：有一个 NaN 就返回 NaN
(cangjie::min x)  (cangjie::max x)    ; 数据分析语义：跳过 NaN
```

为什么要有两套：

- 数学语义下 `NaN` 就该传播，你能从 `NaN` 结果反推「输入里有坏值」；
- 数据分析语义下 `NaN` 是「缺失」而不是「无穷小」，一批数据里有一个空值就让最大值
  变成 `NaN` 是不能接受的。

**加 `cangjie::` 前缀 = 数据分析语义**。这不是重复实现，是两套语义各有正确用法。

## 关系

```lisp
(cangjie::corr x y)          ; 皮尔逊相关系数
(cangjie::cov x y)           ; 协方差（样本）
(cangjie::corr-matrix M)     ; p×p 相关矩阵（M 是 n×p）
```

`corr` / `cov` 是**成对过滤**的：任一侧缺失就丢掉整个样本对。

为什么不能各自独立跳过 `NaN`：那样两个数组会错位，算出来的是「1 号的价格对 5 号的销量」。
数字看着完全正常，结论彻底错。

`corr-matrix` 同样按成对删除缺失：某行在变量 i 上缺失、在 j 上没有时，这一行对
`(i,j)` 不可用，但对其它变量对仍然可用。整行删除会让样本量凭空少一大截。

## 直方图

```lisp
(cangjie::histogram x 10)
;; → {"edges": #<ndarray float64 [...]>, "counts": #<ndarray int64 [...]>}
```

`edges` 有 `bins+1` 个元素，`counts` 有 `bins` 个。这是**可渲染的数据**，
本身不画图。

## 空输入

所有函数在无有效样本时返回 `NaN` 而不是报错。

「没有数据的均值」是未定义的。返回 0 会让调用方拿着一个看起来正常的结果继续算下去；
`NaN` 会一路传播，在最终结果处暴露出来。
