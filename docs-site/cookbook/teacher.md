# 教师工作流：期末成绩能预测吗

一个不懂编程的老师问：**期中成绩能不能预测期末成绩？**

数据：UCI Student Performance，395 名学生 × 33 个字段（`student-mat.csv`）。

## 老师真正想问的是什么

不是「跑个回归」，而是：

1. 期中成绩和期末成绩有关系吗？有多强？
2. 能预测到什么程度？误差多大？
3. 男女生有没有差异？这个差异是真的吗？
4. 这个模型能用来做什么？

下面按这四个问题走。

## 1. 有关系吗

```lisp
(define d (cangjie::csv-read "student-mat.csv"))

(cangjie::corr (hashmap-get d "G1") (hashmap-get d "G3"))   ; 0.8014
(cangjie::corr (hashmap-get d "G2") (hashmap-get d "G3"))   ; 0.9048
```

第一次期中（G1）与期末（G3）相关 0.80，第二次期中（G2）与期末相关 0.90。

关系很强。这不是“有点关系”，而是这两次考试里已经包含了很强的信号。

## 2. 能预测到什么程度

用两次期中成绩预测期末：

```lisp
(cangjie::lstsq X y)      ; X = [1, G1, G2]
;; → [-1.8300, 0.1532, 0.9868]
```

模型：`G3 ≈ -1.83 + 0.153·G1 + 0.987·G2`

| 指标 | 值 |
|---|---|
| R² | 0.8221 |
| RMSE | 1.93 分 |

**R² = 0.82** 说明两次期中成绩解释了期末成绩 82% 的波动。

**RMSE = 1.93 分** 是预测误差的典型量级。换句话说：预测一个学生的期末成绩，
平均会差约 2 分（满分 20）。

这个数字决定了模型能做什么、不能做什么：

- ✅ 能识别出「可能会不及格」的学生（预测 6 分 vs 及格线 10 分，2 分误差不改变结论）
- ❌ 不能用来精确排名（两个学生预测差 1 分，实际谁高谁低完全说不准）

## 3. 男女生有差异吗

```lisp
(define g (cangjie::group-by (hashmap-get d "sex") (hashmap-get d "G3")))
(cangjie::t-test2 (cadr (car g)) (cadr (cadr g)))
```

| 项 | 值 |
|---|---|
| 女生均值 | 9.966 |
| 男生均值 | 10.914 |
| t | -2.065 |
| df | 390.57 |
| **p** | **0.0396** |

p = 0.0396 < 0.05，统计上显著。

但均值只差 0.95 分，而模型的 RMSE 是 1.93 分。这个差异比模型的预测误差还小。

所以正确的结论是：差异在统计上存在，但小到没有实际意义。

这就是为什么 p 值必须和效应量一起看。样本量 395 时，0.95 分的差异足以产生
p < 0.05；如果样本只有 50 人，同样的差异很可能不显著。

## 4. 这个模型能用来做什么

**能**：

- 找出「期中成绩很差、期末可能不及格」的学生，提前干预
- 判断某个学生的期末成绩是不是**异常**（残差特别大的那几个，可能是作弊、生病、
  或者数据录错）

**不能**：

- 评价老师（成绩高低受太多因素影响，不是教学质量）
- 给学生排名
- 预测单个学生的精确分数

## 95% 置信区间

```lisp
(cangjie::ci (hashmap-get d "G3") 0.95)
;; → {"lo": 9.9619, "hi": 10.8683, "mean": 10.4151, "tcrit": 1.9660}
```

平均分 10.42，95% 置信区间 [9.96, 10.87]。区间宽度约 0.9 分，说明这个学校
的平均水平在 10 分上下，离及格线 10 分非常近。

## 数字对得上吗

上述每个数字都用 Python 独立算过一遍（正规方程 + 高斯消元，与 `lstsq` 的 QR
是不同算法）：

| 指标 | 本套件 | Python |
|---|---|---|
| R² | 0.8221 | 0.8222 |
| RMSE | 1.9295 | 1.9296 |
| p | 0.039577 | 0.039577 |
| 95% CI | [9.9619, 10.8683] | [9.9620, 10.8684] |

差在最后一位（显示精度）。**算法不同却给出同一个答案，这才是证据。**
